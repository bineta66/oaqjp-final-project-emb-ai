## Emotion Detector – AI-Powered Web Application

### Project Description

Emotion Detector is an AI-powered web application developed using Python, Flask, and IBM Watson Natural Language Processing (NLP).

The application analyzes a text message and identifies the emotions expressed by the user. It detects five main emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion based on the analysis results.

### Technologies Used

- Python
- IBM Watson NLP
- Flask
- HTML
- CSS
- PyLint
- Unit Testing

### Main Features

- Analyze text and detect emotions.
- Calculate emotion scores.
- Identify the dominant emotion.
- Display results through a web interface.
- Handle invalid or empty inputs.
- Run unit tests to verify the application.

### Project Objective

The objective of this project is to develop and deploy a web application that uses artificial intelligence and natural language processing to recognize emotions in text messages.
